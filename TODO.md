Вот чеклист на основе предложенных ранее идей по развитию сервиса.

### Фронтенд и UX
- [x] **PWA (Progressive Web App):** Добавить `manifest.json` и Service Worker для установки на телефон и работы офлайн.
- [x] **Кастомизация времени:** Иконка настроек для изменения длительности сессий (например, 50/10 вместо 25/5) с сохранением в `localStorage`.
- [ ] **Список задач (Task List):** Блок для ввода текущей задачи и привязки к ней количества завершенных "помидоров".
- [ ] **Фоновые звуки (White Noise):** Воспроизведение аудио (дождь, костер) параллельно с таймером.
- [ ] **Локализация (i18n):** Переключение языков (RU/EN) на фронтенде.

### Бэкенд и аналитика
- [ ] **Регистрация пользователей:** Добавление Flask-Login для сохранения настроек и личной статистики.
- [ ] **Личная статистика (`/me`):** Страница с графиками сфокусированного времени и сериями непрерывных сессий.
- [ ] **Webhooks:** Эндпоинт для отправки уведомлений во внешние сервисы (Notion, Telegram-боты) при завершении таймера.

### Инфраструктура
- [ ] **Кэширование статики в Nginx:** Отдача CSS, JS и шрифтов напрямую через Nginx для разгрузки Gunicorn.
